Filed Under

  1. A heading card opens a tray. Drag it up, or tap it and then tap an empty tray.
  2. File each word in the tray whose heading it belongs under. The game does not tell you which.
  3. On the piles, cards stack only on a card with the same heading. Any card can start an empty pile.
  4. Draw from the inbox when you are stuck. A full tray empties itself and can be reused.

Wrong guesses and hints count as slips. One slip or fewer earns three stamps.
